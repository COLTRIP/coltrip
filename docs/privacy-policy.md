COLTRIP은 부산 관광지 조회, 고요지수 기반 추천, 방문 기록, 좋아요 및 리뷰 기능을 제공합니다. 이 문서는 현재 코드와 배포 문서에서 확인한 개인정보 처리 내용을 설명합니다. 실제 출시 앱과 운영 서버에 같은 버전이 적용됐는지는 별도 검증 대상입니다.

## 1. 처리 목적 및 항목

| 기능 | 처리하는 정보 | 목적·수집 경로 |
|---|---|---|
| 회원가입·로그인 | Google 계정 식별자, 이메일, 내부 사용자 ID, 닉네임, 가입·수정 시각 | Google 인증 및 이용자 입력을 통한 회원 식별, 계정 관리, 작성자 표시 |
| 로그인 유지 | Google ID 토큰, 서비스 액세스 토큰·리프레시 토큰 | 인증 검증, 로그인 유지, 토큰 재발급 |
| 현위치·방문 거리 확인 | 기기의 위도·경도, 선택한 관광지와의 거리 | 위치 권한을 이용한 현위치 표시 및 기기 내 방문 반경 판정 |
| 방문 기록 | 방문 ID, 사용자 ID, 장소 ID, 시작·도착·완료 시각, 방문 상태 | 방문 처리, 진행 중 방문 복원, 이력 조회, 리뷰 작성 자격 확인 |
| 대체 장소 제안 | 방문 시작 고요지수·관측 시각, 후보 장소와 제안 내용, 제안 닫기·알림 처리 시각, 선택으로 생성된 방문 ID | 혼잡도 변화에 따른 제안, 사용자 선택 반영, 중복 제안 방지 |
| 좋아요 | 사용자 ID, 장소 ID, 등록 시각 | 좋아요 등록·해제, 저장 목록 및 상태 표시 |
| 리뷰 | 사용자 ID, 닉네임, 방문·장소 ID, 별점, 한줄평, 작성·수정 시각 | 리뷰 작성·조회·수정·삭제, 작성 자격 확인 |
| 제안 수신 설정 | 대체 장소 제안 허용 여부 | 이용자의 수신 설정 반영. 현재 계정 생성 시 기본값은 허용 |
| 장소 검색·추천 | 지도 조회 영역, 검색어, 카테고리·감성 필터, 기능별 요청 날짜·시간 | 요청 조건에 맞는 관광지·추천 결과 제공 |

Google ID 토큰은 인증 과정에서 처리하고, 서버 회원 테이블에는 리프레시 토큰을 저장합니다. 앱은 서비스 액세스 토큰과 리프레시 토큰을 기기의 보안 저장소에 보관합니다. 토큰 종류마다 저장 위치와 삭제 동작이 다릅니다.

## 2. 위치정보 처리

확인한 최신 develop의 방문 기능은 다음과 같이 처리합니다.

- 방문 시작 요청은 장소 ID만 전달합니다.
- 방문 완료 시 앱이 GPS 위치를 읽고 관광지까지의 거리를 기기에서 계산합니다. 반경 내에 있으면 방문 ID를 사용하는 완료 API를 호출하며 좌표 본문은 보내지 않습니다.
- 현재 백엔드 방문 엔티티에는 사용자 위도·경도 필드가 없습니다. 대신 누가 어느 장소를 언제 방문했는지에 관한 방문 기록은 저장합니다.
- 현재·날짜별 추천 목록 API는 사용자 GPS 좌표를 입력받지 않습니다. 지도 목록 API는 화면 영역의 좌표 범위를 전달하므로, 모든 위치 관련 정보가 서버에 전달되지 않는다는 의미는 아닙니다.
- 네이버 지도 SDK의 현위치 표시 기능을 사용합니다. SDK 자체 정보 처리는 방문 API와 구분하여 확인해야 합니다.

이용자는 기기 설정에서 위치 접근 권한을 허용하거나 철회할 수 있습니다. 거부 시 현위치 표시와 GPS를 이용한 방문 완료 확인이 제한될 수 있습니다.

## 3. 보유기간과 파기

아래는 **현재 코드의 보관·삭제 동작**입니다. 목적 달성·기간 만료 시점의 파기 정책과 운영 설정을 모두 확인한 최종 보유기간표는 아닙니다.

| 정보 | 확인한 보관·삭제 동작 |
|---|---|
| 회원정보 | 탈퇴 시 회원 행 삭제. 일정 기간 경과만으로 삭제하는 정책·배치는 확인되지 않음 |
| 서버 리프레시 토큰 | 재발급 시 교체, 서버 로그아웃 성공 시 해제, 회원 삭제 시 함께 삭제. 토큰 만료가 DB 값 자동 삭제를 뜻하지 않음 |
| 기기 인증 토큰 | 새 토큰으로 교체, 앱 로그아웃 시 삭제, 서버 탈퇴 성공 후 삭제. 일부 인증 실패 처리에서도 삭제 |
| 방문·제안 기록 | 탈퇴 시 연관 방문 삭제. 방문 완료·취소만으로 이력이 삭제되지는 않음 |
| 좋아요·리뷰 | 개별 해제·삭제 또는 회원 탈퇴 시 삭제 |
| FCM 기기 토큰 | 기능 사용 시 해제 API, 탈퇴, 발송 과정의 무효 토큰 판정으로 삭제. 서버 로그아웃만으로는 삭제되지 않음 |
| 일반 로그·백업 | 운영자가 밝힌 정책은 생성 후 24시간 이내 삭제. GitHub 배포 이슈와 백업 문서에는 백업 14일 보관으로 기록되어 있어 실제 보유기간은 검증 전 |
| 과거 위치 데이터·외부 서비스 기록 | 실제 보유 여부, 항목 및 파기 범위가 확인되지 않음 |

회원 탈퇴 API는 리뷰, 좋아요, 방문, 기기 푸시 토큰, 회원정보의 연관 DB 데이터를 삭제합니다. 성공 후 앱의 인증 토큰도 삭제합니다. 서버 로그·백업 사본·외부 서비스의 정보까지 즉시 삭제한다는 의미는 아닙니다.

## 4. 공개 정보와 외부 처리

이용자가 작성한 리뷰는 다른 이용자에게 공개됩니다. 현재 공개 리뷰 응답에는 닉네임, 내부 사용자 ID, 별점, 한줄평, 장소 ID, 작성·수정 시각 등이 포함됩니다. 리뷰에 연락처, 상세한 이동 경로 또는 타인의 개인정보를 작성하지 않도록 주의해 주세요. 공개 사용자 ID의 필요성과 공개 범위에 맞는 고지·처리 근거는 게시 전 점검 대상입니다.

| 서비스 | 확인된 사용 내용 | 확인 범위 |
|---|---|---|
| Amazon Web Services(AWS) | 백엔드·MySQL DB 호스팅 | 배포 이슈에 AWS EC2 서울 리전 및 같은 서버의 MySQL 8.0 |
| Google 로그인 | 앱 계정 인증, 백엔드 ID 토큰 검증 | 계정 식별·인증을 위한 사용 확인 |
| 네이버 지도 | 지도·현위치 표시, 지도 앱 길찾기 연결 | SDK 자체 수집 항목·보관 조건은 계약·정책 대조 |
| COLTRIP AI 서버 | 장소·시간·고요지수 등을 이용한 추천·고요지수 처리 | 코드 확인 |
| Firebase Cloud Messaging | 등록 기기 토큰, 알림 제목·본문, 방문 ID를 이용한 발송 | 백엔드 구현 확인 |

AWS와 DB 구성은 [배포 이슈 #47](https://github.com/COLTRIP/coltrip/issues/47)의 완료 기록에 근거합니다.

백엔드의 AI 대체지 요청에는 장소 식별자, 시간, 주말 여부, 기준 고요지수가 포함되며, 사용자 ID·이메일·원본 GPS 좌표 필드는 없습니다. 관광지 정보와 사용자 원본 좌표를 혼동하지 않습니다.

## 5. 국외 이전

백엔드와 DB는 배포 문서상 국내 서울 리전을 사용합니다.

## 6. 기기 저장 및 로그

앱은 로그인 토큰을 기기의 보안 저장소에 보관합니다.

로그인 코드에는 토큰 존재 여부·길이, 통신 상태와 오류 출력이 있고, 방문 코드에는 방문 응답과 좌표 출력이 있습니다. 실제 출시 빌드·프록시·서버가 수집하는 IP 주소, 요청 URL, 기기 정보, 오류 내용, 보관기간 및 접근권한은 운영 설정과 대조합니다. 웹 쿠키의 설치·운영 여부도 SDK 사용 여부와 동일하게 취급하지 않습니다.

## 7. 이용자의 권리와 처리 경로

이용자는 적용 법령에 따라 개인정보 열람, 정정·삭제, 처리정지 및 동의 철회를 요청할 수 있습니다. 현재 코드에서 확인한 이용자 경로는 다음과 같습니다.

- 내 정보와 활동 확인: 프로필 및 방문·좋아요 목록.
- 닉네임 변경: 프로필의 계정 관리 기능.
- 회원 탈퇴: 프로필 → 계정 관리 → 탈퇴 → 확인. 서버 탈퇴 성공 후 기기 인증 토큰 삭제.
- 위치 권한 변경: 기기 설정의 COLTRIP 앱 권한.
- 개별 좋아요·리뷰 삭제: 해당 기능의 해제·삭제 처리.

## 8. 약관 고지 및 아동

최신 닉네임 설정 화면에는 서비스 이용약관, 개인정보 처리방침, 위치기반서비스 이용약관의 필수 체크박스가 있습니다.

운영자가 안내한 스토어 등급은 전체이용가입니다.

## 9. 안전성 확보조치

코드에는 인증 토큰 검증, 본인 방문·리뷰 등에 대한 권한 확인 및 기기 토큰의 보안 저장소 사용이 구현되어 있습니다. 배포 이슈에는 HTTPS 적용, 운영 비밀 설정의 Git 제외, DB 전용 계정 사용이 완료된 것으로 기록되어 있습니다.

## 10. 방침 공개·변경

현재 앱의 약관 열기 기능은 [GitHub 개인정보처리방침 파일](https://github.com/COLTRIP/coltrip/blob/develop/docs/privacy-policy.md)로 연결됩니다.

시행일과 변경 공지 방법은 운영팀이 정해야 합니다. 최종본은 로그인 없이 읽을 수 있는 고정 HTTPS URL에서 제공하고 시행일·변경 내용·이전 방침을 확인합니다. Git 이력만으로 앱 내 고지나 필요한 별도 동의를 대신했다고 간주하지 않습니다.
