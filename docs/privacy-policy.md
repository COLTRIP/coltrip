리뷰의 별점은 필수이며 한줄평은 선택 항목입니다. 그 밖의 기능별 필수·선택 항목과 거부 시 제한되는 기능은 실제 가입·권한·입력 화면과 일치하도록 확정합니다.

## 2. 위치정보의 처리

COLTRIP은 관광지 방문 시작과 완료 확인 과정에서 기기의 위치정보를 서버로 전송합니다. 방문 시작 좌표는 계정과 연결된 방문 기록에 저장됩니다. 완료 확인 좌표는 목적지와의 거리 판정에 사용되며, 현재 방문 엔티티에는 해당 원본 좌표를 별도로 저장하는 필드가 없습니다. 다만 요청 로그 등에 남는지는 별도 확인이 필요합니다.

현재 확인한 방문 기능은 필요한 시점에 위치를 조회하는 방식이며, 이동 경로를 지속적으로 수집하는 위치 스트림이나 백그라운드 위치 추적 기능은 확인되지 않았습니다. 지도 SDK 등 외부 구성요소의 위치 처리는 제6항 및 제8항과 함께 확정합니다.

이용자는 기기의 앱 권한 설정에서 위치 접근을 허용하거나 철회할 수 있습니다. 권한을 거부하면 GPS를 이용한 방문 확인 기능이 제한될 수 있습니다. 권한 철회나 방문 취소만으로 이미 저장된 방문 좌표와 기록이 자동 삭제되지는 않습니다.

현재 브랜치의 Markdown 링크는 **팀 검토용**으로 공유합니다. 저장소가 비공개라면 권한 없는 사람은 열 수 없으므로 원스토어 공개 URL로 사용할 수 없습니다. 저장소 전체를 공개로 전환하지 않습니다.
